Usa el mismo guion en PC y teléfono

Conecta ambos dispositivos al mismo proyecto de Firebase y entra con la misma cuenta. Los cambios se actualizan automáticamente en los dos.

Sin conexión a la nube
Configuración inicial (solo una vez)
  1. Publica este archivo como sitio web HTTPS, por ejemplo con Netlify Drop. Luego abre esa misma URL en tu PC y teléfono.
  2. En Firebase Console, crea un proyecto y una aplicación web. Copia su apiKey.
  3. En Authentication → Sign-in method, activa Email/Password.
  4. En Realtime Database, crea la base de datos y copia su URL.
  5. En Realtime Database → Rules, pega estas reglas y pulsa Publish:
{
  "rules": {
    "guionero": {
      "$uid": {
        ".read": "auth != null && auth.uid === $uid",
        ".write": "auth != null && auth.uid === $uid"
      }
    }
  }
}

Después abre Guionero desde una dirección web en el PC y el teléfono. En ambos dispositivos usa la misma API Key, URL y cuenta. No publiques la contraseña ni compartas tu cuenta.
